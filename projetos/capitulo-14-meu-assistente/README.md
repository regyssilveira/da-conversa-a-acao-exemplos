# Capítulo 14 — Meu Assistente Digital

Este projeto final ajuda a transformar uma tarefa escolhida pelo leitor numa solução pequena, testável e mantida.

## Materiais

- `dados-ficticios/capitulo-14-canvas-projeto.csv`: definição de tarefa, fronteira e responsabilidade;
- `dados-ficticios/capitulo-14-matriz-testes.csv`: casos mínimos antes de ativar;
- `workflows/capitulo-14-assistente-base.json`: estrutura sem credencial, modelo ou ação externa;
- `guias/caderno-de-operacao.md`: promessa, limites, mudanças, incidentes e desligamento.

## Sequência

1. Preencha o canvas.
2. Personalize somente os dados fictícios do workflow.
3. Execute toda a matriz de testes.
4. Conecte uma fonte real de laboratório e continue com gatilho manual.
5. Faça piloto restrito.
6. Ative automação apenas com monitoramento e forma testada de desligar.

Adicionar IA, agente, canal ou escrita externa é opcional e exige os controles dos capítulos correspondentes.
