# Workflows do n8n

Aqui ficarão os fluxos exportáveis. Os arquivos nunca devem conter credenciais, segredos ou dados pessoais. Cada fluxo será acompanhado por instruções para criar as próprias conexões com segurança.

## Fluxos disponíveis

- `capitulo-05-primeiro-fluxo.json`: três nós, dados fictícios e nenhuma credencial externa.
- `capitulo-06-agenda-para-lista.json`: leitura delimitada do Google Calendar; exige credencial criada pelo leitor.
- `capitulo-06-informacao-para-planilha.json`: inclusão de registro fictício no Google Sheets; exige credencial e planilha de teste.
- `capitulo-12-planejador-diario.json`: agenda e tarefas fictícias para um plano diário conferível.
- `capitulo-12-preparador-reuniao.json`: evento e registros fictícios para um dossiê com fontes.
- `capitulo-12-relatorio-semanal.json`: totais previamente calculados para explicação sem causalidade inventada.
- `capitulo-12-monitor-preco-rss.json`: comparação de preço fictício e ponto de conexão para fonte autorizada.
- `capitulo-13-aprovacao-simulada.json`: aprovação, rejeição e expiração sem envio externo.
