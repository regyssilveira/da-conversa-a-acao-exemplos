# Capítulo 9 - Primeiro agente

Este laboratório cria um agente com apenas uma ferramenta: a calculadora. Ele não possui memória nem acesso a agenda, e-mail, arquivos ou internet.

1. Importe `../../workflows/capitulo-09-primeiro-agente.json`.
2. No nó de modelo, selecione uma credencial do laboratório e um modelo atual compatível com ferramentas.
3. Execute os casos de `../../dados-ficticios/capitulo-09-testes.csv` um por vez.
4. Confira a resposta e o rastro de execução: ferramenta escolhida, argumentos e observação.

O workflow exportado não contém credencial. Interfaces e versões do n8n mudam; se o editor solicitar atualização do nó, confira a documentação oficial vigente antes de salvar.
