# Capítulo 17 — Promoção para operação

## Caminho recomendado

Para quem não administra servidores, comece pelo n8n Cloud. Use este guia como
matriz de decisão; ele não é um tutorial para expor uma instalação à internet.

## Antes de escolher instalação própria

Defina responsáveis por atualização, HTTPS, banco de dados, cópia de segurança,
restauração, segredos, monitoramento e incidentes. Se algum item não possui dono,
permaneça num serviço administrado.

## Adaptação para WhatsApp

Use somente WhatsApp Business Cloud e documentação oficial vigente. Confirme conta
empresarial, consentimento, modelos de mensagem, janela de atendimento, custos,
retenção e encaminhamento humano. Não coloque tokens em workflows exportados.

## Avaliação e viabilidade

Preencha `capitulo-17-avaliacao.csv` para cada versão e trate os casos eliminatórios
como bloqueios de publicação. Depois substitua os valores de exemplo em
`capitulo-17-viabilidade.csv` por observações do piloto. Registre hipóteses; não
apresente a estimativa como garantia financeira.
